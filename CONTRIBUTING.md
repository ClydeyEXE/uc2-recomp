# Contributing

This is a one-person project, and it doesn't take code contributions: no pull requests, patches on forks, or requests
to be assigned an issue or added as a collaborator. Issues are the owner's to-do list, not tasks up for grabs.

What does help:
- Bug reports: what happened, your GPU, and the end of `play_log.txt` (in the folder you unzipped to). No game files.
- Playtest feedback, in the issues that ask for it.

You're welcome to fork the code under its [license](LICENSE) and build on it yourself. For that, see
[docs/BUILDING.md](docs/BUILDING.md), [docs/DEVELOPING.md](docs/DEVELOPING.md) and [docs/HISTORY.md](docs/HISTORY.md).
