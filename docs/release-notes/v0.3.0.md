The third release of Unreal Championship 2 running natively on Windows, recompiled from the original Xbox game.

> **Bring your own game.** This release contains no game data and no code from the game. You need a disc image
> (`.iso`) of your own copy, the USA/Europe release; setup builds the game from it on your machine.

## Getting started
1. Download **Source code (zip)** below and unzip it somewhere with about 3 GB free.
2. Double-click **`Setup.cmd`** and choose your `.iso`. Allow 30-60 minutes.
3. Double-click **`Play.cmd`**. Press **F1** in the game for the settings menu.

## What's new
- **Native widescreen.** Set Aspect to **16:9 (widescreen)** in the settings menu (F1). You see more to the sides
  instead of a stretched picture.
  - The HUD keeps its shape and spreads to the edges of the screen.
  - Menus keep their shape in the middle.
  - Movies and story cutscenes stay 4:3.
  - The window opens in 16:9.

- **Faster in heavy scenes.** The heaviest view tested runs about 12% faster: 65 to 73 fps looking down the long
  corridor on CTF-Aqueduct.

## Known issues
- Choosing Xbox Live (title screen or pause menu) closes the game
- Busy scenes still drop below 60 fps; most of a match runs 60-130 fps
- Occasional 100-160 ms pauses mid-match
- Audio effects such as reverb are missing
- The DLC is not supported

What's being worked on is in the pinned [Roadmap](https://github.com/ClydeyEXE/uc2-recomp/issues/17).

## Reporting a problem
Use the [bug report form](https://github.com/ClydeyEXE/uc2-recomp/issues/new?template=bug_report.yml). It asks for
your version, your GPU and the end of `play_log.txt`. Please attach no game files.
