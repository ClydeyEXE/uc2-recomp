The second release of Unreal Championship 2 running natively on Windows, recompiled from the original Xbox game.

> **Bring your own game.** This release contains no game data and no code from the game. You need a disc image
> (`.iso`) of your own copy; setup builds the game from it on your machine.

## Getting started
1. Download **Source code (zip)** below and unzip it somewhere with about 3 GB free.
2. Double-click **`Setup.cmd`** and choose your `.iso`. Allow 30-60 minutes.
3. Double-click **`Play.cmd`**. Press **F1** in the game for the settings menu.

## What's new
- Glows and cloaked players no longer show through walls
- The match countdown and other short sounds now play
- Anisotropic filtering (2x-16x) in the settings menu
- The version is shown at the foot of the settings menu and written to `play_log.txt`
- A bug report form on the Issues page

## Known issues
- Choosing Xbox Live (title screen or pause menu) closes the game
- Busy scenes drop to 35-48 fps; most of a match runs 60-130 fps
- Occasional 100-160 ms pauses while the game loads files
- Audio effects such as reverb are missing
- The rest of Story Mode is untested, and the DLC is not supported

What's being worked on is in the pinned [Roadmap](https://github.com/ClydeyEXE/uc2-recomp/issues/17).

## Reporting a problem
Use the [bug report form](https://github.com/ClydeyEXE/uc2-recomp/issues/new?template=bug_report.yml). It asks for
your version, your GPU and the end of `play_log.txt`. Please attach no game files.
