The first public release of Unreal Championship 2 running natively on Windows, recompiled from the original Xbox game.

> **Bring your own game.** This release contains no game data and no code from the game. You need a disc image
> (`.iso`) of your own copy; setup builds the game from it on your machine.

## Getting started
1. Download **Source code (zip)** below and unzip it somewhere with about 3 GB free.
2. Double-click **`Setup.cmd`** and choose your `.iso`. It installs Git, Python 3.12 and the Visual Studio 2022 Build
   Tools if they are missing (about 6 GB more, after asking), then builds the game. Allow 30-60 minutes.
3. Double-click **`Play.cmd`**. Press **F1** in the game for the settings menu.

The [README](https://github.com/ClydeyEXE/uc2-recomp/blob/v0.1.0/README.md) has the controls and settings.

## What works
- Full Instant Action matches, start to finish, with an XInput controller or the keyboard
- A Direct3D 11 renderer, with internal resolution up to 4K and stretched 16:9
- A settings menu (F1): resolution, aspect, frame limit, vsync, scaling, FPS counter, skipping the boot waits
- The first quarter of Story Mode, cutscenes included
- Fullscreen with F11 or Alt+Enter

## Known issues
- Busy scenes drop to 35-48 fps; most of a match runs 60-130 fps
- Occasional 100-160 ms pauses while the game loads files
- Audio effects such as reverb are missing
- The rest of Story Mode is untested, and the DLC is not supported

What's being worked on is in the pinned [Roadmap](https://github.com/ClydeyEXE/uc2-recomp/issues/17).

## Reporting a problem
Open an issue with your GPU and the end of `play_log.txt` from the folder you unzipped to. Please don't attach or ask
for game files or builds.
